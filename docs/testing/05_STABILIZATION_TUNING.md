# 自稳（增稳）调参

本文件是**自稳链路**的唯一调参入口：自稳阶段稳定的到底是什么、涉及哪些参数（含
确切参数名、当前值、代码位置）、按什么顺序调、每一步看什么信号、不通过先查哪里。

参数总表见 [`01_PARAMETER_CALIBRATION.md`](01_PARAMETER_CALIBRATION.md)，
分阶段流程见 [`02_TEST_PROCEDURE.md`](02_TEST_PROCEDURE.md)。
本文件与两者的关系：`02` 回答"整个工程按什么顺序推进"，本文件只把其中的
**P2 之前那一段（自稳）** 展开到可以照着做的粒度。

---

## 0. 自稳在整个链路里的位置

自稳是**制导之前唯一的闭环**。它决定镖能不能活着飞到 12.5 m 的捕获点：

```text
发射 → LAUNCH（舵面回中） → STABILIZE ──┐
                          → ACQUIRE  ──┴→ GUIDE → COAST → FAILSAFE / END
                              ↑
                        本文件调的就是这两段
```

自稳段（`PHASE_STABILIZE` + `PHASE_ACQUIRE`）从发射机构脱离一直持续到视觉捕获。
按本任务剖面（25 m 靶距、实测 12.5 m 捕获），这段时间约为 **0.68 s**，
期间**完全没有视觉**——弹道散布只能靠自稳和发射一致性保证。

> 这也是自稳值得单独调的原因：制导只能修正捕获之后的偏差，
> 捕获时的姿态和角速度误差是自稳留给制导的初始条件。

---

## 1. 自稳到底稳了什么（逐轴）

三轴的待遇**不一样**，这决定了调参的重点。

| 轴 | 角度保持（外环） | 角速度阻尼（内环） | 代码依据 |
| --- | --- | --- | --- |
| **滚转** | **有**：`p_cmd = −1.2·flight_roll` | 有：`−kp_p·p − kd_p·ṗ` | `dart_control.c:113`、`rate_control.c:50` |
| **偏航** | 无 | 有：`r_cmd = −0.35·r`，再叠加内环 | `dart_control.c:115` |
| **俯仰** | 无 | **当前被强制关闭**：`my = 0.0f` | `dart_control.c:422-425` |

两个必须先理解的结论：

1. **"自稳"不是"姿态保持"。** 只有滚转有角度基准（`data.roll_ref`，在
   LAUNCH→STABILIZE 跳变时由 `capture_flight_reference()` 锁存）。偏航是纯阻尼
   ——它只反对转动，不回到任何角度。俯仰连阻尼都没有。
2. **俯仰通道的 `my = 0.0f` 抹掉的不是"零指令"。** `stabilization_command()`
   本来就把 `q_cmd` 设成 `0.0f`，所以 `my = 0` 额外抹掉的是
   `−kp_q·q − kd_q·q̇` 这两项**俯仰角速度阻尼**。偏航有对应阻尼、俯仰没有，
   两者不对称。**这是本文件里最需要先确认的一点**，详见 §7.1。

## 2. 参数总表

分四层。**改之前先确认改的是哪一层**——层与层之间是串行的，下层没对好时调上层
没有意义。

### 2.1 前置：姿态估计（`dart_config.h:149-153`）

| 参数名 | 当前值 | 作用 | 什么时候动 |
| --- | --- | --- | --- |
| `DART_AHRS_KP_GROUND` | 1.0 | 地面加速度修正比例 | 台架上静态收敛太慢时增大 |
| `DART_AHRS_KI_GROUND` | 0.015 | 地面陀螺零偏积分修正 | **漂移的唯一对手**；漂了先查这里和零偏标定 |
| `DART_AHRS_ACCEL_MIN_G` / `MAX_G` | 0.86 / 1.14 | 加速度可信区间（±14%） | 动态比力误当重力时收紧 |
| `DART_AHRS_INFLIGHT_ACCEL_WEIGHT` | 0.01 | **飞行中**加速度修正权重 | 见 §7.5，改动前先想清楚 |

> **飞行中姿态基本是陀螺积分的。** `0.01` 意味着飞行段几乎不做加速度修正
> （设计取舍：飞行中比力 ≠ 重力，强行修正反而错）。后果是**滚转姿态会漂**，
> 而滚转姿态是俯仰/偏航舵面作用方向的前提。所以**地面零偏标定
> （`imu_calibrate_gyro_bias()`，`dart_control.c:124`）是自稳的隐式前置条件**，
> 它不在参数表里，但比表里任何一行都关键。

### 2.2 第 1 层：外环 —— 硬编码在 `dart_control.c`，**不在 config 里**

`stabilization_command()`（`dart_control.c:111-116`）：

```c
*p_cmd = clampf(-1.2f * data.flight_roll, -2.0f, 2.0f);
*q_cmd = 0.0f;
*r_cmd = clampf(-0.35f * data.r, -1.0f, 1.0f);
```

| 参数（代码写法） | 当前值 | 物理含义 | 作用 |
| --- | --- | --- | --- |
| `-1.2f * data.flight_roll` | 1.2 | 滚转角误差 1 rad → 指令 1.2 rad/s | 滚转恢复速度；偏高→过冲/摆头 |
| `clampf(..., -2.0f, 2.0f)` | ±2.0 rad/s | 角误差 ≥ 1.67 rad（96°）即饱和 | 大滚转偏差时的角速度上限 |
| `-0.35f * data.r` | 0.35 | 纯偏航角速度阻尼 | 抑制偏航摆振；偏高→偏航高频振 |
| `clampf(..., -1.0f, 1.0f)` | ±1.0 rad/s | r ≥ 2.86 rad/s 即饱和 | 阻尼指令上限 |

> **这四个数要改必须动函数体。** 建议在台架上定值之后顺手提成
> `DART_STAB_ROLL_KP` 之类的宏放进 `dart_config.h`，否则每次调参都变成改代码。

### 2.3 第 2 层：内环 —— `dart_config.h:131-139`，直接改头文件

内环律（`rate_control.c:50-55`）：

```c
*mx = kp_p * (p_cmd - p) - kd_p * p_accel_lpf;
*my = kp_q * (q_cmd - q) - kd_q * q_accel_lpf;
*mz = kp_r * (r_cmd - r) - kd_r * r_accel_lpf;
/* 三轴各自限幅到 output_limit = DART_MOMENT_LIMIT */
```

| 参数名 | 当前值 | 作用 |
| --- | --- | --- |
| `DART_RATE_KP_P` | 0.20 | 滚转角速度内环比例 |
| `DART_RATE_KP_Q` | 0.22 | 俯仰角速度内环比例（**自稳阶段被 `my=0` 架空**） |
| `DART_RATE_KP_R` | 0.26 | 偏航角速度内环比例 |
| `DART_RATE_KD_P` | 0.010 | 滚转阻尼（角加速度反馈） |
| `DART_RATE_KD_Q` | 0.010 | 俯仰阻尼（同上） |
| `DART_RATE_KD_R` | 0.012 | 偏航阻尼 |
| `DART_RATE_ACCEL_LPF_ALPHA` | 0.19 | 角加速度低通每拍系数（200 Hz 下 τ ≈ 23.7 ms，约 6.7 Hz） |
| `DART_MOMENT_LIMIT` | 0.65 | 三轴力矩输出限幅（`rate_control_set_limit`） |

**这几个数的量纲含义（用它判断"是不是调过头了"）：**

| 通道 | 达到 `DART_MOMENT_LIMIT` 所需的角速度误差 `= 0.65 / Kp` | 含义 |
| --- | --- | --- |
| 滚转 | 0.65 / 0.20 = **3.25 rad/s**（186 °/s） | 速率误差超过它，内环就满力矩 |
| 俯仰 | 0.65 / 0.22 = **2.95 rad/s** | 同上 |
| 偏航 | 0.65 / 0.26 = **2.50 rad/s** | 同上 |

若台架上每次阶跃都顶到力矩限幅，说明 `Kp` 相对可用力矩偏大——先查舵效
（`DART_B_*`、`q_scale`），不要继续加 `Kp`。

> **微分项的尺度：** 角加速度 `ṗ = 10 rad/s²` 时 `kd_p` 贡献 0.1 力矩，
> 与 `Kp` 在速率误差 0.5 rad/s 时的贡献相当。`α = 0.19` 的等效 τ ≈ 23.7 ms；
> 若陀螺噪声大导致高频"嗡"，**降 α（加大 τ）** 比降 `KD` 更对症。

### 2.4 第 3 层：分配与执行器 —— `dart_config.h:204-230`、`145`

| 参数名 | 当前值 | 作用 | 备注 |
| --- | --- | --- | --- |
| `DART_SERVO_1..4_DIRECTION` | 全 `-1.0` | 舵面方向 | **自稳反了改这里，不是改增益** |
| `DART_SERVO_SPAN_US` | 500.0 | 归一化 ±1 → ±500 µs | `pulse = center + direction·δ·span` |
| `DART_SERVO_DELTA_LIMIT` | 0.70 | 舵面位置限幅（归一化）→ 折合 ±350 µs | 由分配器施加（`control_allocation.c:153`） |
| `DART_SERVO_RATE_LIMIT_PER_S` | 6.0 | 舵面速率限幅 → 每 5 ms 允许 Δδ = 0.03 | **满行程需 0.33 s**，是主要滞后源之一 |
| `DART_SERVO_DEADBAND` / `BOOST` | 0 / 0 | 死区逆补偿 | 见 §7.6 |
| `DART_B_ROLL/PITCH/YAW_1..4` | ±0.5 / ±0.6 | 舵效矩阵 | 符号错→方向反，幅值错→三轴互相打架 |
| `DART_Q_NOMINAL_SPEED_MPS` | 15.0 | `q_scale = (V_est/15)²`，钳在 [0.2, 4] | **V_est 偏 10% → 控制权限偏 21%** |
| `DART_V_LAUNCH_MPS` / `DART_V_TAU_S` | 18.0 / 3.8 | 决定 `V_est` 衰减 | 与 25 m/2 s 不自洽，见 `04` 第 5.1 节 |

**力矩 → 舵面 / 脉宽的换算（B 矩阵三行两两正交的直接结果）：**

| 力矩通道 | δ1 | δ2 | δ3 | δ4 |
| --- | --- | --- | --- | --- |
| `mx`（滚转） | +0.50·mx | +0.50·mx | +0.50·mx | +0.50·mx |
| `my`（俯仰） | +0.417·my | −0.417·my | +0.417·my | −0.417·my |
| `mz`（偏航） | +0.417·mz | +0.417·mz | −0.417·mz | −0.417·mz |

（系数 = `B[i][j] / Σ_j B[i][j]²`，未计入正则项。）

两个可以直接用的推论：

1. **滚转满力矩只用到 46% 的位置余量。** `mx = 0.65` → `δ = 0.325`，
   而位置限幅是 0.70。**滚转轴的瓶颈是 `DART_MOMENT_LIMIT`，不是舵面行程。**
2. **自稳阶段根本触不到位置限幅。** 自稳时 `my = 0`，只剩 `mx`、`mz`，
   最坏同号叠加 `δ1 = 0.325 + 0.271 = 0.596 < 0.70`。
   所以台架自稳测试里若看到"饱和"，**只可能是速率限幅或矩阵不可逆回中**，
   不可能是位置限幅。

脉宽：`pulse_us = 1500 + direction·δ·500`，四位 direction 均为 −1，
所以 `pulse = 1500 − 500·δ`，正常范围 1150~1850 µs，中位 1500 µs。

## 3. 怎么"看见"自稳

> ⚠ **遥测里已经没有 IMU 量了。** 陀螺仪 `gx/gy/gz` 与加速度 `ax/ay/az` 已从
> `lora_telemetry.c` 的报文里移除（见该文件头部说明）。**内环振荡无法再从遥测
> 复核**，必须换手段。这不是小事——自稳调参的全部依据是角速度响应曲线。

三种可用手段，按推荐顺序：

### 3.1 示波器直接看 PWM（唯一能看实时行为的办法）

四个舵机引脚固定，通道一一对应：

| 通道 | 引脚 | 定时器 |
| --- | --- | --- |
| 舵机 1 | **PB4** | TIM3_CH1 |
| 舵机 2 | **PB5** | TIM3_CH2 |
| 舵机 3 | **PB6** | TIM4_CH1 |
| 舵机 4 | **PB7** | TIM4_CH2 |

时基 1 µs/计数，脉宽 1150~1850 µs，中位 1500 µs。用 §2.4 的换算表把四路脉宽
反推回 `mx/my/mz`，就能看出"滚转在追、俯仰是死的还是活的、有没有限幅"。

判据举例：翻滚被手拨动后，四路脉宽应当**同向**变化（滚转通道特征）；
若出现 2 号、4 号脉宽反着动，那是俯仰通道在参与——而自稳阶段 `my` 本应为 0。

### 3.2 调试器 watch（准静态测试足够，实时不够）

以下变量都能直接 watch（均为文件内 `static`）：

| 看什么 | 在哪 |
| --- | --- |
| 三轴角速度 `p/q/r`、姿态角 | `dart_control.c` 的 `data` |
| 外环指令 `p_cmd/q_cmd/r_cmd` | `stabilization_command()` 局部量，需下断点 |
| 内环力矩 `mx/my/mz` | `dart_control_process()` 局部量，需下断点 |
| 滤波后角加速度 | `dart_control.c` 的 `rate_controller.p/q/r_accel_lpf` |
| 最终舵面归一化值 | `servo.c` 的 `last_delta[4]` |
| 分配器内部状态 | `dart_control.c` 的 `allocator.delta_last[4]` |

> ⚠ SWD 实时读数做不到 200 Hz，而且 `-O2` 下局部变量可能被优化掉。
> **台架调参时用 `-O0` 编译**，并且只用于看"阶跃后稳态值"，不要用它测振荡频率。

### 3.3 临时把字段加回遥测（跑飞行剖面时）

如果必须在实弹/滑轨上复核内环，最省事的办法是在
`lora_telemetry.c` 的 `snprintf` 里**临时**加回 `p/q/r`（约 8 字节/帧，
链路余量见 `02` 的链路核算）。加完记得删。

### 3.4 当前看不到的东西

以下量在代码里算了但**没有任何消费者**，调参时不要指望它们：

| 量 | 现状 |
| --- | --- |
| `saturated`（舵面饱和标志） | `dart_control.c:433` 处 `(void)saturated;` 丢弃 |
| `overrun_count`（控制周期超时计数） | 只写不读 |
| `dart_get_status()` | 定义了，全工程无调用 |

## 4. 调试步骤（严格串行）

**每一步只改一个参数。** 每一步都要在
[`03_TEST_RECORD_TEMPLATE.md`](03_TEST_RECORD_TEMPLATE.md) 留一份记录。

前置：软质无动力镖体 + 刚性约束（转台或万向节）+ 隔离区，首次带电舵面测试
把 `DART_SERVO_DELTA_LIMIT` 临时降到 `0.20f`。

### S0 —— 姿态估计不漂（不做完不要往下走）

| 项 | 内容 |
| --- | --- |
| 目的 | 滚转姿态是唯一有角度基准的通道，它漂了后面全部无意义 |
| 怎么做 | 镖体静止，上电，watch `data.roll` 60 s；再分别绕三轴手动转动，确认 `p/q/r` 符号 |
| 看什么 | `data.roll` 的 60 s 漂移量 |
| 判据 | 漂移 < 1°/min；三轴符号满足右手定则，且与 `DART_BODY_*` 映射一致 |
| 不过 | 重做 `imu_calibrate_gyro_bias()`（要求静止、恒温）；仍漂则查 `DART_AHRS_KI_GROUND` 与传感器温漂 |

### S1 —— 方向确认（**改方向，不改增益**）

| 项 | 内容 |
| --- | --- |
| 目的 | 先保证"推正就是正"，否则后面所有阶跃曲线的符号都是错的 |
| 怎么做 | 临时在 STABILIZE 分支硬编码 `mx = +0.1`（其余置零），观察滚转方向；再对 my/mz 各做一次 |
| 看什么 | 四路 PWM 脉宽是否符合 §2.4 的符号表；机体转向是否符合 §2.4 的定义 |
| 判据 | 三轴方向全部正确，且滚转时四路舵面同向 |
| 不过 | 改 `DART_SERVO_*_DIRECTION`（符号整体反）或 `DART_B_*` 对应行（单路反）。**不要用增益去掩盖方向错误** |

### S2 —— 测一次被控对象（让 S3 有起点，而不是试凑）

| 项 | 内容 |
| --- | --- |
| 目的 | 把"Kp 该取多少"从猜变成算 |
| 怎么做 | 内环 `KD` 置零，外环旁路，直接给固定力矩（如 `mx = 0.3`）并保持 100 ms，记录角速度响应 |
| 看什么 | 角速度上升的时间常数、稳态角加速度（≈ `ṗ`） |
| 判据 | 得到粗略的"力矩 → 角加速度"增益 `K`（rad/s² per 力矩单位）和响应时间常数 |
| 不过 | 若完全没有响应，回到 S1（方向或舵面没接对） |

> **台架的气动不代表飞行。** 约束状态下的 `K` 只能定数量级。但有了它，
> S3 的初值可以按 `Kp ≈ 1/(K·τ)` 量级给，比从 0.20 试起快得多。

### S3 —— 内环 `Kp`，然后 `Kd`（按滚转 → 偏航顺序）

| 项 | 内容 |
| --- | --- |
| 目的 | 建立速率阻尼——自稳的主力 |
| 怎么做 | `KD` 全零，`Kp` 从当前值的 1/3 起，逐次加大；每次给一个角速度阶跃（阶跃 `p_cmd`） |
| 看什么 | 上升时间、超调、是否有**持续**振荡、是否每次都顶到力矩限幅 |
| 判据 | 超调 < 20%，振荡在 2~3 个周期内衰减，大部分阶跃不触到 `DART_MOMENT_LIMIT` |
| 不过 | 见 §5 对照表。**顶限幅先查舵效与 `q_scale`，不要继续加 Kp** |
| 加 `KD` | `Kp` 稳定后再加 `Kd`，从当前值 1/3 起；`Kd` 抑超调，`α` 抑噪声 |
| 顺序 | 滚转（`KP_P`/`KD_P`）→ 偏航（`KP_R`/`KD_R`）。俯仰见 S6 |

### S4 —— 滚转外环（改 `dart_control.c`，不是 config）

| 项 | 内容 |
| --- | --- |
| 目的 | 把"有速度阻尼"变成"有角度基准" |
| 怎么做 | 手动把镖转到某个滚转角，保持，松手；重复 ±30°、±60° |
| 看什么 | 回正时间、过冲、是否来回摆头 |
| 判据 | ±30° 回正无过冲，±60° 过冲 < 20%，多次重复一致 |
| 不过 | 过冲→降 1.2；回正慢→先查速率限幅（满行程 0.33 s 是硬上限）再加 1.2 |
| 限幅 ±2.0 | 角误差 96° 才饱和。若发射初始滚转偏差很大，第一秒会长期饱和——**考虑降低限幅以保护**，而不是加大 |

> ⚠ **外环用的是估计姿态，而飞行中它基本是陀螺积分的（§2.1）。**
> 残余零偏 `b` 会被外环积分成持续指令：`p_cmd = −1.2·b·t`。
> 这是"地面调得好、飞行中滚转越飞越快"的典型机理。**S0 没做扎实时不要调 S4。**

### S5 —— 偏航阻尼（`−0.35` / `±1.0`）

| 项 | 内容 |
| --- | --- |
| 目的 | 抑制偏航摆振。注意这是**纯阻尼，没有角度基准**——它不回到任何方向 |
| 怎么做 | 给镖一个偏航扰动，观察角速度衰减 |
| 看什么 | 衰减包络、是否与 `KP_R` 叠加出高频振 |
| 判据 | 扰动后 2~3 个周期内衰减到 10% 以下 |
| 不过 | 高频振→降 `KD_R` 或降 `α`；衰减慢→加 0.35 或加 `KP_R` |
| 限幅 ±1.0 | r = 2.86 rad/s 饱和。观察 r 是否长期贴在这个值上 |

### S6 —— 俯仰（当前是关的，先决定要不要开）

见 §7.1。若决定开启，最小改动是**删掉 `dart_control.c:422-425` 的 `my = 0.0f`**，
或把 `q_cmd` 改成与偏航同形式的 `−0.35·q`，然后按 S3 的顺序补调
`KP_Q`/`KD_Q`。**开启后必须重跑 S3~S5 的全部阶跃**，因为俯仰一旦有权限，
三轴会在舵面分配里互相影响（虽然 B 正交，但速率限幅是共享的）。

### S7 —— 限幅与动压缩放（最后兜底）

| 项 | 内容 |
| --- | --- |
| `DART_MOMENT_LIMIT` | 只在前面的阶跃都正常、却仍触限幅时下调。注意滚转满力矩只用掉 46% 位置余量，**通常该改的是 `Kp` 而不是它** |
| `DART_SERVO_RATE_LIMIT_PER_S` | 6.0 → 满行程 0.33 s。**先实测舵机带载能否达到**；达不到就是"限制器说谎"，实际滞后比它更差 |
| `DART_Q_NOMINAL_SPEED_MPS` / `V_est` | `q_scale = (V_est/15)²`。速度模型未实测前，**台架调好的 `Kp` 搬到飞行段不一定成立**——这是台架-飞行不一致的头号原因，见 `04` 第 5.1 节 |

### S8 —— 发射瞬态复测

S3~S7 全绿之后，回到 [`02_TEST_PROCEDURE.md`](02_TEST_PROCEDURE.md)
第 11 节，用真实发射（低能量）复测：LAUNCH→STABILIZE 跳变时
`rate_control_reset()` 清空滤波器状态（`dart_control.c:271`），
舵面应当从"回中"平滑转入"自稳"，**不应出现跳变或短暂反向**。

## 5. 故障对照表

| 现象 | 先查 | 再改 |
| --- | --- | --- |
| 舵面回正是**反向**的 | `DART_SERVO_*_DIRECTION`、`DART_B_*` 符号 | S1，不要动增益 |
| 低频摆振 2~5 Hz，越拨越晃 | 该轴 `Kp` 过高 | 降 `Kp` |
| 俯仰方向明显摆振、滚转偏航都正常 | **`my = 0.0f`（§7.1）** | 决定是否开启俯仰阻尼 |
| 高频"嗡"或啸叫 | `Kd` 过大 / `α` 过大（τ 太小） | 降 `Kd`，或**降 `α`** |
| 回正很慢但最后能回 | 速率限幅（满行程 0.33 s） | 先实测舵机速率，再考虑降 `DART_SERVO_RATE_LIMIT_PER_S` |
| 回正慢**且**舵面早就到位 | 舵效 `DART_B_*` 偏小 / `q_scale` 偏小 | 重标舵效矩阵 |
| 静止时滚转角有固定偏差 | 正常：外环是 P，**没有积分**，恒值扰动力矩必然留静差 | 想要零静差需加积分，或靠 `DART_GUIDANCE_PITCH_BIAS_RATE` 一类偏置（仅制导段） |
| 地面正常，飞行中越飞越快（滚转） | 陀螺零偏被外环积分（§4 S4 警示） | 回 S0，重标零偏 |
| 偶发某一拍舵面回中 | IMU 单次读失败 | 已是"零横向力矩+保留滚转"降级（`imu_fallback_output()`），查 SPI 与 EMI |
| 阶跃每次都顶到力矩限幅 | `Kp` 相对可用舵效过大 | 先查舵效/`q_scale`，再降 `Kp` |

## 6. 与制导段的交界（调自稳会牵动制导）

**内环是共用的。** `rate_control_update()` 在自稳和制导两段用的是**同一组
`Kp`/`Kd`**。改了自稳的内环，制导段的响应也一起变了——**一个旋钮，两个环**。
调完自稳后必须重跑制导段的验收（`02` 第 10 节）。

| 交界点 | 行为 | 注意 |
| --- | --- | --- |
| LAUNCH → STABILIZE | `rate_control_reset()` 清 LPF 与 `have_previous`；`guidance_reset_target()`；弹道估计重置 | 首次发射才锁存 `roll_ref`（`data.ref_valid`） |
| STABILIZE / ACQUIRE 期间的 `t_go` | 恒为 `1.5f`（`dart_control.c:347` 的兜底值） | 落在 `ca_get_T_go_weights` 的 `>0.5` 档（w_roll 0.3）。**因 B 正交，权重只通过正则项 `λ/w` 起作用，近似无效** |
| GUIDE | 同样的内环，指令来自制导律 | 滚转指令律**换了**：自稳用 `−1.2·roll`，制导用 `DART_GUIDANCE_ROLL_KP`(1.4) |
| FAILSAFE / IMU 降级 | `guidance_failsafe()`：`p_cmd = clamp(−0.8·roll, ±1.0)` | **滚转增益在这里是 0.8，比自稳的 1.2 小**；滚转权限在失效时是下降的 |

> 制导段的滚转增益（1.4）与自稳段（1.2）不同，这是有意的（末端要求更强滚转
> 保持以保证俯仰/偏航作用方向）。**两条律的滚转增益要一起看**，不要只调一条。

## 7. 已知问题与待确认

按优先级排列。前三条会直接影响自稳能否调好。

### 7.1 `my = 0.0f` 抹掉了俯仰角速度阻尼（**建议优先确认**）

`dart_control.c:422-425`：

```c
if (flight_state.phase == PHASE_STABILIZE
|| flight_state.phase == PHASE_ACQUIRE) {
my = 0.0f;
}
```

- `stabilization_command()` 已把 `q_cmd` 设为 `0.0f`，所以这个置零**在指令层面
  是冗余的**；它实际抹掉的是 `−kp_q·q − kd_q·q̇`，即**俯仰的全部角速度阻尼**。
- 对照：偏航通道通过 `r_cmd = −0.35·r` 明确保留了阻尼。**两轴不对称。**
- 后果：整个 0.68 s 的开环段俯仰无阻尼，短周期摆动不会被抑制；
  进入制导后俯仰指令又从零开始建立，初始条件是带摆动的。
- 这段代码没有注释，缩进也与周围不一致，看起来是**临时改动**。

**待确认：这是有意为之（例如为保护发射机构）还是遗留？** 本文件不假定答案，
先由台架 S6 实测俯仰摆振幅度再决定。

### 7.2 外环增益硬编码在 `.c` 里

`−1.2`、`±2.0`、`−0.35`、`±1.0` 四个数在 `stabilization_command()` 函数体内。
参数分类（`01`）把它们归在"闭环调参"，但它们**不在 `dart_config.h`**，
调参要改代码。建议台架定值后提成宏。

### 7.3 遥测不含 IMU，内环无法在飞行中复核

见 §3。自稳的可观测性目前**完全依赖台架**。若要在实弹/滑轨上复核，
需临时加回 `p/q/r` 字段。

### 7.4 饱和 / 超时 / 状态码全部不可见

`saturated` 被丢弃、`overrun_count` 只写不读、`dart_get_status()` 无调用者。
**自稳调参最需要的两个健康指标（饱和、周期超时）目前都拿不到。**

### 7.5 飞行中滚转姿态靠陀螺积分

`DART_AHRS_INFLIGHT_ACCEL_WEIGHT = 0.01`，飞行段几乎不做加速度修正。
这是有意的取舍（飞行中比力 ≠ 重力），但代价是**滚转姿态漂移**，
而滚转是俯仰/偏航舵面作用方向的前提。缓解手段只有地面零偏标定。

### 7.6 `DART_SERVO_DEADBAND = 0` 时死区逆补偿会除零

`control_allocation.c:58-68` 的 `deadband_inverse()` 做了 `delta / db`。
`db = 0` 时结果是 `±inf`，`fminf(inf, 1.0f) = 1.0f`，最终返回
`delta ± boost`。**当前 `BOOST = 0` 所以无害**；但若单独把 `BOOST` 设成非零
而 `DEADBAND` 仍是 0，会得到**一个恒定偏置而不是补偿**。
两者要改必须同时改。

### 7.7 `DART_SERVO_RATE_LIMIT_PER_S` 是"限制器"，不是"实测值"

6.0/s 意味着满行程 0.33 s。它限制的是**分配器输出的变化率**，
不代表舵机真的能做到。台架必须实测带载速率；若舵机更慢，
这个限制器只是在滞后之上再加一层滞后。
