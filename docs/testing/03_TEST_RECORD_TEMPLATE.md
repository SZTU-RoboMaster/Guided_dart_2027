## 必录数据

> ⚠ **遥测报文里已经没有 IMU 量了**（陀螺仪 `gx/gy/gz` 与加速度 `ax/ay/az` 已从
> `lora_telemetry.c` 移除），也没有姿态角、LOS 角/LOS 角速度和制导指令。

> 否则多数调参依据无法复核。

### A. 遥测报文（LoRa，USART1 @ 115200，约 20 Hz）

实际报文字段：`L` 锁定 / `X``Y` 像素偏差 / `T` 飞行时间 / `BV` 弹道有效 /
`TY``TP` 航迹偏航俯仰 / `TYR``TPR` 航迹角速度 / `TG` 当前 `t_go` /
`TA` 捕获瞬间 `t_go` / `DF` 首个有效距离(dm) / `CF` 置信度峰值。

| 记录项 | 值 |
| --- | --- |
| 原始日志文件名 |  |
| 视觉锁定 `L`：首次为 1 的时刻 |  |
| 捕获瞬间 `TA` |  |
| 首个有效距离 `DF` 及当时 `T` |  |
| 置信度峰值 `CF` |  |
| `TG` 是否单调递减（有无跳变） |  |
| `X`/`Y` 符号与目标移动方向是否一致 |  |
| 丢帧/`L` 掉 0 的次数与时刻 |  |

> **`TA` 与 `DF` 通常不是同一帧**：捕获首帧目标只有 1 px 半径，视觉端量不出距离
> （按协议发 0），所以 `DF` 会晚于 `TA` 出现。读数时不要以为记录错了。
