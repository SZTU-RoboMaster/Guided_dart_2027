## 优先级定义

| 优先级 | 阶段 | 放行条件 |
| --- | --- | --- |
| P0 | 上电与安全检查 | 电源、通信、IMU、舵机中位和急停正常 |
| P1 | 必须实测标定 | 坐标系、相机、舵机、舵效矩阵和系统延迟已有实测值 |
| P2 | 约束闭环调参 | 角速度内环稳定，视觉 LOS 方向正确，无持续饱和 |
| P3 | 低能量飞行验证 | 发射检测、短时丢失、速度模型和航迹估计通过对照验证 |
| P4 | 完整制导优化 | 重复飞行结果稳定后再优化命中精度和末端参数 |

## 参数标记

- **必须实测**：必须使用当前实物测量或辨识，不能沿用默认值直接飞行。
- **闭环调参**：没有唯一物理真值，需要依据阶跃响应、稳定性或命中误差调整。
- **数据调参**：有真值，但要先采集数据（遥测/图像）才能算出该填多少。
- **现场调参**：随光照、目标和场地变化，应使用现场图像数据调整。
- **必须核对**：通常保持不变，但必须确认两端配置或设计约定一致。
- **通常固定**：除非硬件或系统设计变化，否则不需要修改。

## 强制原则

- 每次只修改一个控制层或一组强相关参数。
- 每次测试都记录固件版本、参数、供电电压、测试条件和原始数据。
- 首次带电舵面测试将 `DART_SERVO_DELTA_LIMIT` 临时限制为 `0.20f`。
- 姿态、舵面方向和舵效矩阵未通过前，不启用视觉制导。
- 姿态链路（含航迹估计交叉校验）未通过前，不启用视觉制导。
- 相机安装误差只能用相机安装偏角修正，不能用制导俯仰偏置掩盖。
- `DISTANCE_CALIBRATED` 已置 `True`（`DIST_A` 标定完成）；改动 `DIST_A`/`DIST_B`
  后须重新验证 `t_go` 连续性。

> ⚠ **遥测报文中已不含任何原始 IMU 量。** 陀螺仪 `gx/gy/gz` 与加速度 `ax/ay/az`
> 均已从 `lora_telemetry.c` 移除，姿态角、LOS 角和制导指令也从未上报过。
> 因此**发射判定、姿态估计和内环振荡都无法从遥测复核**——必须用台架示波器
> 直接看 PWM，或临时把字段加回 `snprintf`。完整清单见
> [`05`](05_STABILIZATION_TUNING.md) 第 3 节。

## 本任务（25 m 剖面）附加原则

详见 [`04_MISSION_PROFILE.md`](04_MISSION_PROFILE.md)。要点：

- 25 m 处目标约 3.6 px，**视觉采集是本任务的瓶颈，不是导引律**。
  未在 **12.5 m**（实测捕获距离）下确认捕获率与跟踪连续性前，不得进入制导闭环。
- 全程制导指令不到限幅的 3%，**不做 APN / ISMCG 的 A/B 对比调参**，
  保持 `DART_GUIDANCE_MODE_ISMCG = 0`。
- 速度模型当前与 25 m / 2 s 不自洽（预测行程 28 m），
  必须先用实测速度曲线修正 `DART_V_LAUNCH_MPS` / `DART_V_TAU_S`。
  **`V_est` 偏 10% → 控制权限 `q_scale` 偏 21%**，这是台架-飞行不一致的头号原因。
- 目标停止瞬间是本任务唯一的关键瞬态，台架必须先复现完整时序再上弹。
