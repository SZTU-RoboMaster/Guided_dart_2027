# 视觉制导效果验证与调参指南

本文用于判断当前视觉制导链路是否真正有效，并指导参数调整。测试对象是本工程的 STM32 固件与 `openmv_vision_guidance_2027.py`，协议为 V5。任何带舵面或发射测试都必须使用软质训练镖、机械约束、拦截网和急停；未通过前一级验收，不进入下一级。

## 1. 测试目标和判据

要验证的不是“舵面会动”，而是以下闭环关系：

```text
目标位置变化 -> OpenMV 有效帧 -> STM32 LOS 角/角速度 -> q/r 指令
-> 控制分配 -> 舵面方向正确 -> 镖体角速度向减小视线误差的方向变化
```

建议把“可行”定义为：

- 视觉有效帧率稳定，丢帧后能按预期进入 HOLD/COAST/FAILSAFE；
- 目标在画面右侧时，制导修正不会把目标推向更右侧，目标停止后指令能平滑回落；
- 舵面没有持续饱和，`q_cmd/r_cmd` 能被角速度内环跟踪；
- 在重复的低能量任务剖面中，命中误差和散布满足项目要求。

## 2. 测试前固定条件

1. 确认 OpenMV 烧录的是工程内的 `openmv_vision_guidance_2027.py`，STM32 与 OpenMV 均为当前协议 V5。
2. 核对 USART2：921600 baud、8 数据位、无校验、1 停止位。
3. 首次带电测试将 `DART_SERVO_DELTA_LIMIT` 临时设为 `0.20f`，舵面装好后再逐步恢复；确认急停能让四路回中。
4. 先断开连杆完成舵机中位、方向、行程和速率测试；再装连杆做控制分配测试。
5. 测试记录中保存固件版本、参数版本、供电电压、目标距离、光照和原始日志。一次只改一个参数或一组明确相关参数。

## 3. 分阶段测试流程

### T0：通信和视觉单机测试

固定相机和目标，开启 OpenMV `DEBUG_PRINT`，观察：

```text
fps、valid、cx、cy、r、conf、dist、blobs
```

目标在画面中心、左/右/上/下各停留 10 s，记录有效帧率、误检和丢检。STM32 端观察 `vision_link_stats_t.good_frames` 连续增加，`crc_errors` 和 `uart_errors` 不应持续增长。遮挡目标后应先失效，再按超时进入保护。

验收：目标移动方向与 `cx/cy` 变化一致；有效帧率和延迟满足后续测试要求。若 T0 不通过，不调制导增益。

### T1：静态目标 LOS 符号测试（不发射）

将镖体固定在转台或支架上，目标位于已知方位。让目标依次位于画面中心、右侧、左侧、上方、下方，记录 `los_yaw/los_pitch` 及其速率。镖体绕 roll 轴小角度转动，目标不动，确认滚转补偿后 LOS 不随画面滚转产生同等幅度的假信号。

若当前遥测没有这些字段，使用调试器观察 `guidance_output_t`，或临时在遥测中增加字段：`LY/LP/LYR/LPR/q_cmd/r_cmd/TG`。测试期间不要同时改滤波和制导增益。

验收：符号、零点和滚转补偿正确，静止目标的 LOS 速率接近零。

### T2：制导方向和舵面方向测试（约束台架）

保持镖体固定，仅移动目标。先将 `DART_GUIDANCE_K_ACCEL_FEED`、`DART_GUIDANCE_K_CAPTURE` 和 `DART_GUIDANCE_PITCH_BIAS_RATE` 设为 0，只保留比例导引主项。目标向右移动，观察 `r_cmd`、分配后的四路 `delta` 和实际偏航力矩；目标向上移动，重复观察 `q_cmd` 和俯仰力矩。每次先用很小的目标偏移，再逐步增加。

正确结果是：控制动作使预测弹道朝目标误差减小的方向变化。出现反向时按第 5 节处理，不能用增益大小掩盖符号错误。

### T3：停止瞬态测试

用滑轨或视频回放复现“目标先横向移动，约 1.2 s 后随机停止”。重点观察停止前后至少 0.3 s 的 `LYR/LPR`、`q_cmd/r_cmd`、`TG` 和舵面输出。正确结果是目标停止后 LOS 速率逐步衰减，指令无明显阶跃和反向大幅过冲。

### T4：低能量飞行测试

先关闭视觉制导，仅验证发射状态机和自稳。随后以低能量、缩短距离、固定目标进行视觉闭环；每次只增加一个变量：捕获距离、目标横移幅度、速度或制导增益。至少重复 5 次，记录首次捕获时刻、丢帧、最大舵偏、命中点和是否进入 failsafe。

### T5：任务剖面测试

在接近实际的 25 m 距离、560 mm 横向范围和 1.2 s 停止时序下重复测试。先确认速度模型满足 `∫V(t)dt` 与实际距离一致，再验证 `t_go`。若视觉在 12.5 m 附近才捕获，应重点统计捕获距离和捕获后的剩余时间；捕获太晚时，继续加大增益通常不能弥补时间不足。

## 4. 可调整参数及效果

### OpenMV 视觉参数

| 参数 | 位置 | 调大/调小的典型效果 |
| --- | --- | --- |
| `FPS_TARGET` | OpenMV 脚本 | 目标帧率；过高可能导致处理超时和实际 FPS 下降 |
| `GREEN_THRESHOLDS` | OpenMV 脚本 | 颜色召回率与误检率；范围过宽会误检，过窄会漏检 |
| `BLOB_PIXELS_MIN`、`BLOB_AREA_MIN/MAX` | OpenMV 脚本 | 最小目标尺寸和杂点抑制；过大可能漏掉远处目标 |
| `ROI_HALF_TRACK` | OpenMV 脚本 | 跟踪窗口大小；过小易丢目标，过大会增加计算量和误检 |
| `ROI_FULL_SCAN_EVERY` | OpenMV 脚本 | 全图重扫周期；更小利于重捕获但降低帧率 |
| `CONF_ACCEPT`、`CONF_STRONG`、`CONF_REACQUIRE` | OpenMV 脚本 | 置信度门控；提高可减少误检但会延迟捕获 |
| `DIST_A`、`DIST_B` | OpenMV 脚本 | 半径到距离的标定模型；错误会污染 `t_go` |
| `EXPOSURE_US`、`GAIN_DB` | OpenMV 脚本 | 亮度、拖影和噪声；先保证目标轮廓，再追求帧率 |

### STM32 视觉状态和延迟参数

| 参数 | 典型效果 |
| --- | --- |
| `DART_VISION_CONF_ACQUIRE/HOLD` | 获取和保持门槛；过高易进 FAILSAFE，过低易误锁 |
| `DART_VISION_FRESH_MS/COAST_MS/FAILSAFE_MS` | 对短时丢帧的容忍时间；必须保持递增 |
| `DART_VISION_LOCK_FRAMES` | 连续有效帧数；增加可降低误锁但增加捕获延迟 |
| `DART_CAMERA_FX/FY/CX/CY_PX` | 像素到 LOS 角的比例和零点；必须使用实测标定值 |
| `DART_CAMERA_YAW_OFFSET_RAD/PITCH_OFFSET_RAD` | 相机安装角补偿；只修正固定安装误差 |
| `DART_CAMERA_PIPELINE_DELAY_S` | 视觉采集到 STM32 收帧的预测延迟；偏小会滞后，偏大会超前过度 |
| `DART_SERVO_DELAY_S` | 舵面执行延迟；偏小会滞后，偏大会造成相位超前过量 |

### 制导和滤波参数

| 参数 | 典型效果 |
| --- | --- |
| `DART_GUIDANCE_YAW_SIGN`、`DART_GUIDANCE_PITCH_SIGN` | 制导指令整体符号；只应取 `+1` 或 `-1` |
| `DART_GUIDANCE_NAV_RATIO` | 比例导航强度；增大可更快追踪，但更易饱和、振荡 |
| `DART_GUIDANCE_K_CAPTURE` | 远距把目标拉回视场中心；过大可能造成末端过载 |
| `DART_GUIDANCE_K_ACCEL_FEED` | 目标横向加减速前馈；噪声大或停止瞬态过冲时应先置零 |
| `DART_GUIDANCE_FILTER_ALPHA/BETA` | LOS 位置和速率响应；增大更灵敏但更噪 |
| `DART_GUIDANCE_FILTER_RATE_TAU_S` | LOS 角速度低通时间常数；增大更平滑但滞后更大 |
| `DART_GUIDANCE_FILTER_DD_TAU_S` | LOS 角加速度差分低通；增大可抑制停止瞬态反向尖峰 |
| `DART_GUIDANCE_RATE_LIMIT` | `q/r` 指令限幅；过低跟不上，过高会把内环推入饱和 |
| `DART_GUIDANCE_PITCH_BIAS_RATE` | 固定俯仰角速度偏置；只用于重复的系统性落高/落低，最后调 |
| `DART_GUIDANCE_NEAR_TGO_S/FAR_TGO_S` | `t_go` 对应的远近端权重调度；依据实测捕获时刻回填 |

### 角速度内环、舵机和分配参数

| 参数 | 典型效果 |
| --- | --- |
| `DART_RATE_KP_P/Q/R` | 角速度误差响应强度；过大易振荡或触发力矩限幅 |
| `DART_RATE_KD_P/Q/R` | 阻尼；应在 KP 稳定后逐步加入 |
| `DART_RATE_ACCEL_LPF_ALPHA` | 角加速度微分滤波；过小会滞后，过大易放大噪声 |
| `DART_MOMENT_LIMIT` | 三轴力矩上限；过低跟踪不足，过高可能导致舵面饱和 |
| `DART_SERVO_*_CENTER_US` | 舵机机械中位；错误会造成持续偏转 |
| `DART_SERVO_*_DIRECTION` | 单路 PWM 正方向；舵面方向反时优先改这里 |
| `DART_SERVO_SPAN_US` | 归一化舵偏对应的脉宽范围 |
| `DART_SERVO_DELTA_LIMIT` | 舵面位置限幅；先小后大，防止连杆撞限位 |
| `DART_SERVO_RATE_LIMIT_PER_S` | 舵面变化速率；过低产生明显滞后 |
| `DART_B_ROLL/PITCH/YAW_1..4` | 控制分配矩阵；决定每个轴由哪些舵面、以多大相对效能产生 |
| `DART_Q_NOMINAL_SPEED_MPS` | 动压缩放基准；速度估计偏差会平方影响控制权限 |

## 5. 制导方向反了时怎么改

按以下顺序定位，禁止同时改多个方向参数：

1. **先确认视觉坐标方向。** 目标向画面右移时 `cx` 是否增大，向上移时 `cy` 是否减小；若不对，修 OpenMV 图像坐标或相机安装标定。
2. **再确认 LOS 符号。** 目标右/上移动时 `los_yaw/los_pitch` 是否按工程约定变化。若固定偏差不随目标移动，改 `DART_CAMERA_YAW_OFFSET_RAD` 或 `DART_CAMERA_PITCH_OFFSET_RAD`，不要改 `*_SIGN`。
3. **若 LOS 正确、`q_cmd/r_cmd` 方向反，改制导符号：**

   ```c
   #define DART_GUIDANCE_YAW_SIGN    (-1.0f)  /* 偏航整体反向时 */
   #define DART_GUIDANCE_PITCH_SIGN  (-1.0f)  /* 俯仰整体反向时 */
   ```

   每次只改一个轴，并重新执行 T2。

4. **若 `q_cmd/r_cmd` 正确但实际角速度或舵面力矩反，改执行器层：**
   - 单路 PWM 正负方向反：修改对应 `DART_SERVO_1..4_DIRECTION`；
   - 某一控制轴的组合方向或相对效能反：检查并实测对应 `DART_B_PITCH_*`、`DART_B_YAW_*`、`DART_B_ROLL_*`；
   - 不要通过把 `KP` 设成负数来修方向。

5. **若方向只在镖体滚转后反，检查 `DART_BODY_*` 映射矩阵、右手定则和滚转补偿，而不是改制导符号。**

每次改动后记录：目标移动方向、LOS 符号、指令符号、四路舵偏、实测角速度符号。四者必须形成一致链路。

## 6. 推荐调参顺序

1. 舵机中位、方向、行程、速率和控制分配矩阵；
2. IMU 映射、姿态角和角速度内环 `KP -> KD`；
3. OpenMV 阈值、曝光、ROI、置信度和实际帧率；
4. 相机内参、安装偏角和总延迟；
5. LOS 符号与滚转补偿；
6. 置零 `K_CAPTURE`、`K_ACCEL_FEED`、`PITCH_BIAS_RATE`，从较小 `NAV_RATIO` 开始调；
7. 逐步加入 `K_CAPTURE`，再加入 `K_ACCEL_FEED`；
8. 最后按重复落点误差调 `PITCH_BIAS_RATE`，并按实测捕获时刻回填 `NEAR_TGO/FAR_TGO`；
9. 每次只改一个参数，至少重复 3 次再判断趋势，完整任务剖面至少重复 5 次。

## 7. 视觉制导容易超调时的诊断与调参

先区分三种情况，不要一看到落点越过目标就直接降低所有增益：

| 现象 | 优先怀疑 | 首先调整 |
| --- | --- | --- |
| `q_cmd/r_cmd` 自身出现大尖峰，目标停止后马上反向 | 视觉角速度或角加速度前馈噪声 | `DART_GUIDANCE_K_ACCEL_FEED`、滤波时间常数 |
| `q_cmd/r_cmd` 平滑，但实际 `q/r` 来回振荡 | 角速度内环过强或舵面响应造成相位滞后 | 对应轴 `DART_RATE_KP_*`、`DART_RATE_KD_*` |
| 指令和角速度都不尖锐，但整体修正越过目标 | 制导外环强度或延迟补偿不合适 | `DART_GUIDANCE_NAV_RATIO`、`DART_GUIDANCE_K_CAPTURE`、延迟参数 |

### 推荐调节顺序

1. **先关闭最容易放大噪声的加速度前馈。**

   ```c
   #define DART_GUIDANCE_K_ACCEL_FEED 0.0f
   ```

   当前值为 `0.5f`。目标停止、减速或视觉检测跳变时出现反向尖峰，先置零验证；如果超调明显减小，说明问题主要来自 `λ̈` 前馈，而不是导航比。确认 `LYR/LPR` 足够平滑后，再从 `0.1f` 或 `0.2f` 小幅恢复。

2. **降低比例导航强度。**

   ```c
   #define DART_GUIDANCE_NAV_RATIO 3.0f
   ```

   建议按 `3.0 -> 2.5 -> 2.2` 逐级测试，每次降低约 10%～20%，每个值至少重复 3 次。当前置信度缩放下有效导航比最低约为 `3.0 × 0.7 = 2.1`，不要在没有记录的情况下继续大幅降低，否则可能变成跟踪不足。该参数主要改善“目标越过后再摆回”的外环超调。

3. **降低远距离视场拉回项。**

   ```c
   #define DART_GUIDANCE_K_CAPTURE 0.6f
   ```

   建议测试 `0.6 -> 0.4 -> 0.2 -> 0`。如果只有远距离目标偏离画面时修正过猛，优先调此项；如果近距离也振荡，则优先回到 `NAV_RATIO` 或内环检查。该参数过大可能在末端产生较大的横向指令。

4. **过滤视觉角速度和角加速度。**

   当 `LYR/LPR` 有明显高频尖峰，而目标实际运动平滑时，可适当增大：

   ```c
   #define DART_GUIDANCE_FILTER_RATE_TAU_S 0.093f
   #define DART_GUIDANCE_FILTER_DD_TAU_S   0.205f
   ```

   可先试 `0.093 -> 0.12 s` 和 `0.205 -> 0.25 s`。增大时间常数会降低噪声和停止瞬态过冲，但会增加滞后；如果目标移动时已经明显跟不上，不要继续增大，应先检查帧率和延迟标定。`DART_GUIDANCE_FILTER_ALPHA/BETA` 也不要与时间常数同时修改。

5. **检查相位延迟参数。**

   ```c
   #define DART_CAMERA_PIPELINE_DELAY_S ...
   #define DART_SERVO_DELAY_S           ...
   ```

   这两个值必须来自实测。值填得过小，控制表现为滞后并容易越过目标；值填得过大，预测超前会造成提前反向和振荡。不能用继续降低 `NAV_RATIO` 来掩盖错误延迟。

6. **最后处理角速度内环。**

   如果 `q_cmd/r_cmd` 平滑，但实测 `q/r` 持续来回变化，分别降低对应的 `DART_RATE_KP_Q` 或 `DART_RATE_KP_R`，每次降低 10%～20%；稳定后再逐步增加对应 `DART_RATE_KD_Q/R` 提供阻尼。不要把 `KP` 改成负数修方向，方向错误应按第 5 节排查。

### 指令限幅的使用

```c
#define DART_GUIDANCE_RATE_LIMIT 3.5f
```

若确认方向、延迟和内环均正确，但末端偶发指令打满，可临时降到 `3.0f` 或 `2.5f`，用于限制最大横向指令。它只能限制后果，不能替代 `NAV_RATIO`、前馈和滤波的正确调节；限幅后若命中误差变大，说明系统已经受到控制权限限制。

### 每次调参必须记录的量

- `LY/LP`：LOS 角；
- `LYR/LPR`：LOS 角速度；
- `q_cmd/r_cmd`：制导输出；
- 实际 `q/r`：角速度内环响应；
- 四路舵面 `delta`、是否饱和；
- `TG`：剩余时间估计；
- 目标停止前后至少 0.3 s 的峰值、过零次数和衰减时间。

判定规则：降低某参数后，若 `q_cmd/r_cmd` 峰值和过零次数下降、目标停止后的误差仍能收敛，调节方向正确；若指令平滑但 `q/r` 仍振荡，应停止调视觉参数，转调角速度内环；若目标误差越来越大而不是越过后回来，先检查符号、舵效矩阵和相机坐标。
